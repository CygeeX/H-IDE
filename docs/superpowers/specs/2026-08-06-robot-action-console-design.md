# 工作站机器人行动控制平面设计

本项目是工作站上的机器人行动控制平面，不是机器人 Agent 依赖框架，也不替代机器人侧 Robot Agent。它通过稳定的 `AgentGateway` 接入现有规划框架，通过受控适配器连接机器人侧 Agent、HTTP、MQTT 和工作站 ROS 2 服务。

浏览器只访问 BFF 的 HTTPS/WebSocket/WebRTC 接口。手动操作、Agent 计划和语音输入统一转换为高层命令，经过确认、策略、租约、幂等和审计后才能执行。接口变化通过版本化声明式映射、能力探测、dry-run 和原子回滚处理；协议或语义变化必须发布新的适配器 Driver。

首版目标是单工作站、多机器人、WireGuard 直连、响应式 PWA，并将场景、视频和语音模块与控制运行时隔离。物理急停和机器人本地安全监控始终是最高安全层。
