03 WHAT THIS PROVES

01

白名单翻译

网页只知道 power.enable，ROS 名称与类型始终留在机器人本地配置。

02

控制租约

只有 ACTIVE 会话可发命令；续租停止后，Robot Agent 在本地触发安全态。

03

幂等与终态

命令 ID、TTL、资源仲裁和 SQLite 台账共同避免重复下发与状态漂移。

04

数据收敛

只上传归一化状态与 Action feedback，不把完整 ROS graph 和高带宽数据暴露到远端。
